# TARJETA DE ESTADO

Genera esta tarjeta con los datos reales de la sesión y entrégala en un bloque
para copiar. Es solo por si cierran el chat y vuelven otro día. Si van a seguir
ahora, díselos: que la guarden y sigan.

Nunca la escribas de forma que se lea como la siguiente instrucción.

## Plantilla

```
CLAUDE EN MARCHA: MI TARJETA DE ESTADO

Negocio: [una frase, en sus palabras]
Plan: [gratis / Pro / Max / Team / Enterprise]
Dispositivo: [escritorio Mac / escritorio Windows / navegador]

Avance:
[x] 1. Diagnóstico
[x] 2. Primer entregable
[ ] 3. Perfil permanente
[ ] 4. Conectores
[ ] 5. Proyecto
[ ] 6. Entrevista
[ ] 7. Diseño del reporte
[ ] 8. Destino
[ ] 9. Horario
[ ] 10. Cierre

Lo que ya existe de verdad:
- Proyecto: [nombre, o ninguno]
- Conectado: [calendario / correo / archivos / nada]
- Instrucciones de perfil: [escritas y probadas / escritas sin probar / no]
- Reporte: [diseñado / en horario / no]

Pendientes:
- [lo que quedó abierto y por qué]

Para retomar: abre un chat nuevo, pega esta tarjeta, y escribe:
"Lee https://joework.co/claude/setup/inicio.md y continúa desde donde quedé."
```

## Cómo llenarla
Solo marca lo que probaste. Si escribieron instrucciones de perfil pero no las
probaron en un chat nuevo, eso va como "escritas sin probar", no como hecho.

En pendientes, sé específico y honesto. "Cowork bloqueado por el administrador,
pedir habilitación a sistemas" sirve. "Falta terminar" no sirve.
