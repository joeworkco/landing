# Claude en Marcha · archivos de la guía

Estos son los trece archivos que Claude lee mientras te configura, publicados en
abierto para que puedas revisarlos antes de correr nada.

**La guía completa:** https://joework.co/claude

## Cómo se usa

Abre un chat nuevo en Claude y pega:

```
Lee https://joework.co/claude/setup/inicio.md y ponme en marcha.
```

## Qué es cada archivo

| Archivo | Qué hace |
|---|---|
| `inicio.md` | El conductor. Le dice a Claude cómo llevar la sesión completa. |
| `00-diagnostico.md` | Paso 1. Desde dónde arrancas. |
| `01-entregable.md` | Paso 2. El primer archivo real, con datos tuyos. |
| `02-perfil.md` | Paso 3. Instrucciones permanentes de perfil. |
| `03-conectores.md` | Paso 4. Calendario, correo y archivos. |
| `04-proyecto.md` | Paso 5. Darle casa al trabajo recurrente. |
| `05-entrevista.md` | Paso 6. Claude te entrevista a ti. |
| `06-reporte.md` | Paso 7. Diseñar el reporte diario. |
| `07-destino.md` | Paso 8. Dónde aterriza. |
| `08-horario.md` | Paso 9. Automatizarlo. |
| `09-cierre.md` | Paso 10. Qué construiste y qué sigue. |
| `coach.md` | Modo rescate, cuando algo falla dos veces. |
| `estado.md` | Tarjeta de avance, para retomar otro día. |

## Por qué están en abierto

Nunca deberías pegar un enlace en Claude sin poder leer primero qué dice. Un
archivo remoto puede darle instrucciones que tú no ves. Estos están aquí con su
historial de cambios completo, para que compruebes que nada se modificó en
silencio.

Sin registro, sin correo, sin formulario.
